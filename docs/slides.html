CrewAI em Python

Da anotação de aula ao quiz

Arthur Lemos / Seminário de Python

Uma equipe lê uma anotação sobre pilhas e prepara duas perguntas para a turma.

O que a CrewAI coordena?

Agent define quem trabalha

O analista seleciona os conceitos. O professor usa esses conceitos para escrever perguntas.

Task descreve a entrega. Crew reúne os agentes e as tarefas. Process.sequential define a ordem.

O que um agente entrega ao outro?

Anotação de aula

Em uma pilha, o último item inserido sai primeiro. Em Python, append() insere no fim da lista e pop() retira o último item.

O analista resume essa regra. O professor recebe o resumo como contexto para criar o quiz.

Onde a colaboração aparece no código?

context=[resumir]

O parâmetro context da tarefa criar_quiz indica qual resultado anterior deve chegar ao professor.

equipe.kickoff(inputs={"anotacao": texto}) inicia as duas tarefas com a anotação escolhida.

Qual item sai primeiro?

pilha = ["A", "B"] print(pilha.pop())

Pense na ordem de entrada antes de responder.

Na demonstração, compare o gabarito com a anotação original.

Como conferir o resultado?

Sai “B”. A pilha fica com [“A”].

Se o gabarito divergir, confira primeiro o resumo. Isso ajuda a localizar em qual etapa o erro apareceu.

O modo demonstração usa respostas fixas. No modo IA, um modelo gera o texto a cada execução.

Para reproduzir o projeto

python seminario.py --demo

O README explica como instalar a versão usada e executar o mesmo fluxo com um modelo de linguagem.
